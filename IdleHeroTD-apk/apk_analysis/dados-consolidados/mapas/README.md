# Mapas

Categoria consolidada para bonus fixos, perks e bonus de posicionamento dos mapas.

## Leitura principal

- `bonus_fixos.md`: bonus/penalidades fixos exibidos no painel de cada mapa.
- `bonus_resumo.md`: resumo de perks e bonus de posicionamento.

## Referencia tabular

Os CSVs ficam em `csv/` e servem para planilha, scripts e auditoria:

- `bonus_fixos.csv`
- `perks.csv`
- `bonus_slots_posicionamento.csv`
