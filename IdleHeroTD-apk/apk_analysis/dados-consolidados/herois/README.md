# Herois

Categoria consolidada para herois e sinergias.

## Leitura principal

- `herois_compilado.md`: stats, skills e resumo por heroi.
- `sinergias_por_heroi.md`: mapa de sinergias para IA montar times.
- `sinergias_resumo.md`: resumo da extracao das sinergias.

## Referencia tabular

Os CSVs ficam em `csv/` e servem para planilha, scripts e auditoria:

- `catalogo_herois.csv`
- `detalhes_herois.csv`
- `sinergias_por_heroi.csv`
- `sinergias_mapa.csv`
- `sinergias_arestas.csv`
- `sinergias_matriz.csv`
