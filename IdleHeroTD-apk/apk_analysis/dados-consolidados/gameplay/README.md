# Gameplay

Categoria consolidada para metadata, campos e candidatos de mecanicas de gameplay.

## Leitura principal

- `gameplay_metadata_index.md`: indice legivel de metadata de gameplay.
- `gameplay_system_fields.md`: resumo legivel dos campos de sistemas.
- `mechanics_candidates.md`: resumo legivel dos candidatos de mecanicas.
- `metadata_core_contexts.md`: contextos centrais de metadata.

## Referencia tabular

Os CSVs ficam em `csv/` e servem para planilha, scripts e auditoria:

- `gameplay_metadata_terms.csv`
- `gameplay_system_fields.csv`
- `mechanics_candidates.csv`
